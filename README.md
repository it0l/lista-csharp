# Exercícios de C#

Coleção acadêmica com 25 exercícios introdutórios de C#, reunidos em uma aplicação de console.

## Conteúdos praticados

- entrada e saída no terminal;
- operações aritméticas;
- estruturas condicionais;
- laços de repetição;
- criação e chamada de métodos;
- arrays de tipos primitivos e objetos;
- classes, campos e métodos;
- cálculos e alterações de estado em objetos.

Entre os exemplos estão tabuada, verificação de números, cálculos de média, manipulação de arrays e exercícios com as classes `Carro` e `Funcionario`.

## Executando

~~~bash
git clone https://github.com/it0l/lista-csharp.git
cd lista-csharp
dotnet run --project Projeto/Projeto.csproj
~~~

## Observação

Este repositório representa uma etapa de aprendizado e preserva soluções diretas, próximas ao conteúdo estudado em aula.
